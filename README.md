# 네이버 쇼핑 연관 키워드

네이버 쇼핑 검색 API로 상품을 조회하고, 결과를 JSON으로 저장하며 연관 키워드를 모으는 연습입니다.

| 분류 | 상태 | 스택 | 바로 보기 |
| --- | --- | --- | --- |
| 자동화 · API | 연습 | Python · 네이버 검색 API | — |

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `step_1_1.py` | `output/` 폴더 생성 |
| `step_1_2.py` | `datakart`로 쇼핑 검색 API 호출 → 결과 JSON 저장 |

API 키는 [네이버 개발자 센터](https://developers.naver.com/)에서 발급받아 환경 변수로 넣어 쓰세요.
